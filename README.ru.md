# CRT Overlay

[English](README.md) · **Русский**

Атмосфера ЭЛТ для игр, фильмов, аниме и ретровидео. CRT Overlay обрабатывает рабочий стол Windows в реальном времени: добавляет сканлайны, структуру люминофора, свечение, кривизну стекла и послесвечение поверх привычного контента.

Модифицировать игру не нужно. Запустите её или видеоплеер в оконном режиме либо без рамки, выберите пресет и настройте изображение в живом редакторе. Оверлей пропускает клики в приложения под ним.

**Версия 1.0.3 · Windows x64 · Лицензия MIT**

## Возможности

- Сканлайны, RGB-маски, зависимость ширины луча от яркости, bloom, halation, сведение, фокус, шум и геометрия.
- Soft, Balanced, Strong, Rolling и стили PSX, Mega Drive, SNES, Master System, Game Boy.
- Отдельный профиль кинескопа Philips A51EAL155X с документированными цветами, шагом полос и поверхностью стекла.
- Редактор с мгновенным предпросмотром выбора пресета и ползунков, импортом/экспортом JSON и интерфейсом RU/EN.
- Управление из трея, горячие клавиши, обработка курсора и послесвечение с интегрированием rolling-экспозиции.

Назначение — приятная атмосфера просмотра. Это приближённый эффект дисплея, а не эмулятор консоли или калиброванная замена настоящего ЭЛТ. Game Boy — стилизация LCD. [Ограничения модели](docs/ru/CRT-RESEARCH.md).

## Быстрый старт

Скачайте ZIP последнего релиза для Windows x64 из [GitHub Releases](https://github.com/Tomm1ck/CRT-Overlay/releases/latest). **Code → Download ZIP** скачивает исходники, а не готовую программу.

1. Установите **.NET Runtime 9 x64**, если его нет. Для готового релиза SDK не нужен; один Runtime 10 не заменяет Runtime 9.
2. Распакуйте весь ZIP в доступную для записи папку. Сохраните рядом `app`, `presets` и BAT-файлы.
3. Запустите `Start.bat` для Balanced либо `Editor.bat` для редактора.
4. Выберите пресет из списка. Включите **Предпросмотр на рабочем столе**, чтобы сразу видеть результат, и настройте ползунки по вкусу.
5. **Применить** оставляет настройки на текущий сеанс. **Сохранить в файл…** записывает их в файл JSON, который можно открыть позже.
6. Завершите работу через `Stop.bat`, меню трея или **Ctrl+Alt+Shift+Q**, если сочетание доступно.

**Требования:** Windows 10 2004/build 19041 или новее, Windows 11; x64; GPU с Direct3D 11 feature level 11.0, работающий драйвер Desktop Duplication и SDR. Обрабатывается один монитор. Расчёт учитывает 60, 59,94 и 144 Гц; фактический вывод зависит от Windows, драйвера и нагрузки GPU.

## Выбор атмосферы

| Пресет | Изображение |
|---|---|
| `Soft` | Мягкие сканлайны, маска, кривизна и свечение |
| `Balanced` | Базовая настройка |
| `Strong` | Более заметная структура и геометрия трубки |
| `Rolling` | Развёртка 60 Гц с компенсацией средней яркости; BFI выключен |
| `PSX` / `PSX-Composite` | 320×240, RGB555, дизеринг PS1; вариант с приближённым composite |
| `MegaDrive` / `MegaDrive-Composite` | 320×224, RGB333; вариант с приближённым composite |
| `SNES` | 256×224, RGB555 |
| `MasterSystem` | 256×192, RGB222 |
| `GameBoy` | 160×144, четыре зелёных оттенка, стилизация LCD |
| `Philips-A51EAL155X` | Документированный профиль трубки с вписанной областью примерно 4:3 |

**Исходный / Startup** в трее возвращает параметры текущего запуска. Это не имя CLI-пресета.

Готовый Philips доступен в трее и редакторе. Чтобы совместить трубку с другим стилем, сначала выберите стиль, затем **Расширенные настройки → Физический профиль трубки → Кинескоп → Philips A51EAL155X**. Это профиль кинескопа; конкретное шасси телевизора не заявляется.

Геометрия и размер области меняют изображение, но **не переназначают координаты кликов Windows**. При сильной кривизне или уменьшении области видимые цели и курсор могут расходиться с реальными позициями кликов. Эти режимы удобнее для просмотра и управления клавиатурой/геймпадом.

## Управление и язык

Двойной щелчок по значку трея открывает редактор. Все сочетания используют **Ctrl+Alt+Shift**:

| Клавиша | Действие |
|---|---|
| `Q` | Выход |
| `F11` | Включить/выключить эффект |
| `F10` | Следующий пресет |
| `F5` | Перекомпилировать шейдеры |
| `E` | Открыть редактор |

Если сочетание занято другой программой, например G-Helper, отключается только это сочетание на текущий сеанс. Приложение продолжает работу; действие остаётся в трее. После освобождения сочетания перезапустите CRT Overlay.

При первом открытии редактор показывает **Основные настройки**: яркость, выраженность строк и маски, свечение и кривизну по двум осям. Для тонкой настройки выберите **Расширенные настройки**, затем нужный раздел. Переключение между видами сохраняет ваши правки; если вы ещё не закончили вводить число, сначала исправьте его.

Вверху редактора видно, какой пресет или файл вы меняете. Пометка **«изменён»** и звёздочка в заголовке означают, что вы отошли от его исходных значений. Внизу редактор отдельно показывает, применили ли вы изменения и записали ли их в файл. Если вы выключили эффект через трей или горячую клавишу, редактор тоже сообщит об этом.

**Применить** оставляет изменения на экране, но не записывает файл. **Сохранить в файл…** делает и то и другое; позже вы сможете загрузить этот вариант через **Открыть файл…**. Пока вы не применили изменения, кнопка **Отменить и закрыть**, Escape и крестик возвращают последние применённые настройки. После применения кнопка меняется на **Закрыть**. Выключение предпросмотра также показывает последние применённые настройки и не стирает ваши правки в полях.

**Вернуть пресет** восстанавливает исходные значения выбранного пресета или открытого файла. Пункт **Применённые настройки** в списке возвращает последний применённый вариант. **Сбросить основные** восстанавливает стандартные значения шести основных параметров, а **Сбросить раздел** — параметров выбранного расширенного раздела. Остальные параметры при таком сбросе не меняются. Полный пресет заменяет параметры изображения; отдельный выбор трубки сохраняет остальные настройки.

Язык переключается в редакторе и трее. Он хранится в `%LOCALAPPDATA%\CrtOverlay\ui.json`, отдельно от графических пресетов. CLI и ключи JSON одинаковы на обоих языках.

## Примеры запуска

Из папки распакованного релиза или корня репозитория:

```powershell
.\Start.bat --preset Soft
.\Start.bat --preset Philips-A51EAL155X
.\Start.bat --preset PSX --tube-profile philips-a51eal155x --tube-content stretch --curvature 0
.\Editor.bat
.\Stop.bat
```

В сеансе пользователя работает один экземпляр. Обычный повторный запуск не заменяет его настройки: используйте редактор/трей либо сначала остановите программу. `--editor`, `--language` и `--stop` обращаются к работающему экземпляру. Батники `Start-PSX`, `Start-Sega`, `Start-SNES`, `Start-MasterSystem`, `Start-GameBoy` и `Start-Rolling` останавливают и перезапускают программу с выбранным стилем.

## Ограничения

- Оконный режим или без рамки; exclusive fullscreen и HDR не поддерживаются. Защищённое видео может быть чёрным.
- Обрабатывается готовый рабочий стол. Консольные стили не воспроизводят игровую логику, геометрию GPU, палитры игр или дрожание вершин PS1.
- Composite — приближённая YIQ-фильтрация, без полноценного NTSC/PAL-кодера и декодера.
- Затухание, форма луча, фокус и рассеяние оценочные. Philips сочетает паспортные данные и явные допущения, а не измерения целого телевизора.
- На LCD 60 Гц полная развёртка 60 Гц может укладываться в один кадр без бегущей полосы. Интегрирование не воспроизводит физический импульс ЭЛТ. BFI затемняет часть выходных кадров и снижает среднюю яркость.
- Задержка и FPS зависят от системы; универсальные показатели и совместимость не гарантируются. G-Sync/VRR зависят от драйвера и композитора.
- Окна исключаются из собственного захвата. Если Windows не подтверждает исключение, запуск прекращается, чтобы не захватывать оверлей повторно.

## Решение проблем

| Проблема | Что сделать |
|---|---|
| Не запускается | Проверить .NET Runtime 9 x64 и журнал |
| Не работает хоткей | Использовать трей; в журнале указано занятое сочетание |
| Не видно изменений | Включить предпросмотр, обновить EXE и перезапустить после обновления |
| Ошибка исключения из захвата | Передать полный журнал, сборку Windows, GPU/драйвер и тип сеанса |
| Неверные цвета | Выключить HDR Windows |
| Защищённое видео чёрное | Программа не обходит DRM |
| Нужен обычный курсор | Перезапустить с `--cursor system` |
| Нет полосы rolling на 60 Гц | Это может быть нормальным результатом интегрирования полного кадра |

Журнал: `%LOCALAPPDATA%\CrtOverlay\crt.log`, заменяется при запуске основного экземпляра. Пути вида `/_/CRT-Overlay/src/...` в стеке — ссылки на исходники при сборке, а не файлы, которые программа ищет на вашем ПК.

## Диагностика производительности

Пропускаются 16 GPU-проходов свечения, когда **Bloom и Halation одновременно равны нулю**, в том числе в пресете Game Boy. Если включён хотя бы один эффект, работает прежний конвейер из пяти уровней. Ожидание следующего кадра использует таймер Windows вместо активного цикла. Реальный выигрыш зависит от настроек и ПК.

Чтобы включить необязательный журнал, запустите новый экземпляр:

```powershell
.\Start.bat --performance-log on
```

Если программа уже работает, сначала выйдите через трей или `Stop.bat`. Флаг применяется при запуске и не сохраняется в пресет. Раз в 10 секунд `crt.log` записывает частоту Present/захвата, среднее и максимальное время Render вместе с ожиданием Present, загрузку CPU процесса относительно всех логических процессоров и выборочное GPU-время CRT-проходов. Запросы GPU не ждут готовности; недоступные результаты отмечаются `n/a`. Это не общая загрузка GPU и не задержка ввода. [Расшифровка полей](docs/ru/PARAMETERS.md#performance-log).

