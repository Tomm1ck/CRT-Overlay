# Сборка и упаковка

[English](../BUILDING.md) · **Русский** · [Руководство](../../README.ru.md)

## Требования

Windows x64 и .NET SDK 9.0.306 либо более свежий патч ветки 9.0.3xx (`global.json`). Для восстановления пакетов нужен NuGet. Сборка использует Windows PowerShell и системную `d3dcompiler_47.dll`. C++-компилятор, WPF, WinForms и внешний `fxc` не нужны.

Проект использует `net9.0`, `WinExe`, `win-x64`. Vortice закреплён на 3.8.3, а Vortice.Mathematics имеет отдельную нумерацию — 2.1.0. При изменении зависимостей сохраняйте `packages.lock.json`.

## Компиляция и публикация

Из корня репозитория:

```powershell
dotnet build
dotnet publish crt.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o app
```

Сборка компилирует C# и варианты HLSL. На другом ПК нужен .NET Runtime 9 x64. Шейдеры встроены в EXE и компилируются также при создании конвейера во время работы.

Если EXE занят, выберите другую папку публикации. `Build.bat` намеренно останавливает текущий оверлей перед обновлением `app`; команда выше этого не делает. В Release пути исходников заменяются на `/_/CRT-Overlay`, чтобы журнал не раскрывал каталог пользователя на компьютере сборки.

Однофайловая публикация добавляет пакет инструментов ILLink даже без trimming. Обычная сборка и publish могут менять эту запись lock-файла; итоговый lock-файл сохраняется после публикации.

## Архив релиза

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/Package-Release.ps1
```

Скрипт читает версию из `crt.csproj`, публикует в новую временную папку и добавляет только выбранные запускатели, пресеты, данные профиля, документацию и лицензии. Рабочая папка `app` остаётся отдельной от архива.

Результат:

- `artifacts/releases/CRT-Overlay-v1.0.0-win-x64.zip`
- `artifacts/releases/CRT-Overlay-v1.0.0-win-x64.zip.sha256`

Существующие архивы не перезаписываются. Для повторной сборки укажите `-OutputDirectory artifacts/releases-review`. Промежуточные файлы остаются в `artifacts/release-staging` для просмотра. Результаты сборки и старые архивы исключены из Git.

Архив требует отдельной установки Runtime 9 и не имеет цифровой подписи. `BUILD-INFO.json` содержит версию, SDK, конфигурацию, требования к Runtime и время сборки UTC. В архиве нет установщика .NET, исходного репозитория, личных путей, журналов и настроек языка пользователя. Сохраняйте структуру папок при распаковке.

Загрузите ZIP и SHA-256 в GitHub Release с соответствующим тегом версии. Каталоги `app`, `bin`, `obj`, `.local` и `artifacts` не добавляются в исходный репозиторий. Для следующего релиза обновите версию в `crt.csproj`, оба README и журналы изменений.
