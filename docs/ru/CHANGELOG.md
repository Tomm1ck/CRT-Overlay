# История изменений

[English](../../CHANGELOG.md) · **Русский**

## 1.0.0 — 2026-10-15

Первый публичный релиз.

- CRT-эффекты поверх оконных и безрамочных игр и видео через Direct3D 11 и DirectComposition.
- Строки, RGB-маски, луч, bloom, halation, геометрия, сведение, послесвечение, опциональные rolling exposure и BFI.
- Пресеты Soft, Balanced, Strong, Rolling, PSX, Mega Drive, SNES, Master System и Game Boy.
- Профиль кинескопа Philips A51EAL155X с паспортными данными и явными допущениями модели.
- Живой редактор, импорт/экспорт JSON, Apply/Cancel и русский/английский интерфейс.
- Трей, BAT-запускатели и независимая регистрация хоткеев с обработкой занятых сочетаний.
- Диагностика исключения окон из захвата и обезличенные пути исходников в стеке Release.
- Пропуск 16 GPU-проходов свечения при нулевых Bloom и Halation, в том числе в пресете Game Boy.
- Ожидание кадров через таймер Windows с обработкой сообщений; счётчики выделения памяти только в явном режиме диагностики с ограничением времени.
- Необязательный `--performance-log on`: частоты Present/захвата, время Render, загрузка CPU процесса и асинхронные выборочные GPU-замеры эффектов.
- Документация RU/EN, лицензия MIT и уведомления зависимостей.

Требуются Windows x64, SDR и .NET Runtime 9 x64. Поддерживаются схемы пресетов 1 и 2.
