# Contributing

**English** · [Русский](docs/ru/CONTRIBUTING.md) · [README](README.md)

Bug reports and focused improvements are welcome. For a bug, include the release version, Windows build, GPU/driver, display mode and refresh rate, exact steps, preset/settings, and relevant log lines from `%LOCALAPPDATA%\CrtOverlay\crt.log`. Review logs for personal information before sharing. Say whether the session is local or remote and whether other software uses the same hotkeys.

For changes, read [Architecture](docs/ARCHITECTURE.md) and [Building](docs/BUILDING.md). Keep legacy presets compatible, preserve independent console and tube settings, and update English/Russian labels and docs together. New physical data needs a source, units, conditions, and a clear distinction between documented values, measurements, and estimates. Do not claim a measured match from visual similarity alone.

Keep the change focused. Explain the problem and resulting behavior, and make sure the change compiles. Do not commit build outputs, logs, personal session notes, credentials, or third-party manufacturer PDFs.

Contributions are provided under the project's [MIT license](LICENSE). Preserve third-party notices and document new dependencies and their licenses. Do not submit assets you lack permission to redistribute.
